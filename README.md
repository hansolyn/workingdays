# 근태 현황 대시보드

근태 시스템에서 내려받은 월별 `rawdata.xlsx`를 올리면 출퇴근·체류시간·휴가 현황을 보여 주는 단일 페이지 도구입니다.

## 사용 방법

1. 페이지를 열고 `rawdata.xlsx`를 올립니다. 최대 3개(3개월치)까지 함께 올릴 수 있습니다.
2. 처음 쓰는 PC에서는 **인원 설정 > 설정 불러오기**에서 설정 파일(`근태대시보드_설정.json`)을 불러온 뒤 저장합니다.
3. 파일 없이 화면만 보려면 첫 화면의 **샘플 데이터 보기**를 누릅니다. 가상 인물 데이터이며, 샘플을 보는 동안 바꾼 설정은 저장되지 않습니다.
4. 설정은 그 PC의 브라우저에만 저장됩니다. 다른 PC에서 쓰려면 **설정 내보내기**로 받은 파일을 그 PC에서 다시 불러옵니다.

설정 파일을 불러오기 전에는 조직도와 재량근로 부서가 비어 있어, 모든 부서가 '미배정'·일반 직원으로 집계됩니다.

## 개인정보

- 올린 엑셀 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
- 이 저장소에는 `rawdata.xlsx`와 설정 파일(`.json`)을 올리지 마세요. 직원 이름과 근태·휴직 정보가 들어 있습니다.
- 이 페이지에는 직원 이름과 조직도가 들어 있지 않습니다.
